# LearningPlaywright Repository

This repository contains a learning project for JavaScript fundamentals and Playwright-related practice. It is organized by chapter folders, with sample code and notes for each topic.

## Repository Structure

- `Chapter_01_Basics/`
  - Introduces basic JavaScript programming concepts through small example files.
  - Contains:
    - `01_Basic.js` — prints text and a variable to the console.
    - `02_JS.js` — shows variable assignment, loops, functions, and console output.
    - `04_hot code.js` — demonstrates a simple loop that logs a counter.

- `Chapter_02_Javascript_Concepts/`
  - Contains more JavaScript practice code and examples for basic JS behavior.
  - Contains:
    - `05_JS.js` — assigns a variable, updates it, and logs the result.

- `chapter_03_Identifier_Literals/`
  - Focuses on identifier rules, naming conventions, comments, and VS Code shortcuts.
  - Contains:
    - `06_Identifier_Rules.js` — valid identifier examples and invalid naming patterns.
    - `07_Identifier_Part2.js` — naming convention examples like camelCase, PascalCase, snake_case, and constants.
    - `08_Comments.js` — single-line, multi-line, and JSDoc-style comment examples.
    - `VS_Code_keyboard_shortcut_windows.md` — useful Visual Studio Code shortcuts for Windows.
    - `README.md` — detailed chapter notes for identifier and literal topics.

## What This Project Covers

- JavaScript basics: console output, variables, loops, functions, and assignment.
- Naming conventions and identifier rules in JavaScript.
- Comment types and how to document code.
- Productivity tips for using Visual Studio Code on Windows.
- A Git-based learning workflow with chapter folders for gradual progress.

## How to Use This Repository

1. Open the project in Visual Studio Code.
2. Explore the chapter folders to review code examples and notes.
3. Open `Chapter_01_Basics` for beginner JavaScript exercises.
4. Open `Chapter_02_Javascript_Concepts` for more JS practice.
5. Open `chapter_03_Identifier_Literals/README.md` for detailed notes on identifiers, naming conventions, and comments.
6. Add new chapter folders as you continue learning, such as `Chapter_04`, `Chapter_05`, etc.
